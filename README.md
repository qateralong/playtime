# Playtime

Server-side Fabric mod: /playtime shows total play time, and players can hide their own.

## Features

- `/playtime` shows your total play time, or another player's.
- `/playtime hide` and `/playtime show` let players control their own visibility.

## Compatibility

Minecraft 1.21.1, Fabric Loader and Fabric API. Runs on the server; players need no client mod.

## Build

```bash
./gradlew build
```

The jar appears in `build/libs/`.
